## Сборка

Собирается `pdflatex` (удобнее через `latexmk -pdf`).

Кроме обычных пакетов нужен **cm-super** — он даёт Type 1 контуры для
кириллицы в кодировке T2A. Без него pdfTeX подставляет растровые шрифты
(Type 3), и в `домашние_задания.pdf` и `семинар2_натуральная_дедукция_правила.pdf`
кириллица перестаёт искаться и копироваться, а на печати выглядит хуже.
Слайдов это не касается: там подключён `dejavu`.

* MiKTeX: `miktex packages install cm-super`
* TeX Live: обычно уже установлен, иначе `tlmgr install cm-super`
